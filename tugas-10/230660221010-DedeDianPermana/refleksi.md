\### 1. Bagian Tersulit dalam Integrasi Data



Bagian tersulit dalam pengerjaan tugas ini adalah menggabungkan data pengguna dan data pengajuan dari dua endpoint API yang berbeda. Proses penggabungan harus menggunakan userId agar setiap pengajuan dapat menampilkan nama pengguna yang sesuai.



\### 2. Penanganan Data Kosong dan Error



Untuk menangani kondisi data kosong dan error, aplikasi menggunakan pengecekan status respons HTTP, try-catch, serta tampilan loading dan pesan kesalahan. Aplikasi juga menyediakan tombol untuk mencoba mengambil data kembali apabila terjadi kegagalan.



\### 3. Pentingnya Pemisahan Service dan Widget



Pemisahan service dan widget penting agar kode program lebih terstruktur dan mudah dipelihara. Service bertanggung jawab mengambil serta mengolah data dari API, sedangkan widget bertanggung jawab menampilkan data kepada pengguna.
