\# Catatan Keputusan UI/UX



\## 1. Warna Benih



\*\*Pilihan:\*\* Menggunakan warna biru sebagai warna utama aplikasi.



\*\*Alasan:\*\* Warna biru digunakan sebagai warna benih pada tema aplikasi karena memberikan kesan sederhana, bersih, dan mudah dilihat. Warna ini juga diterapkan melalui `ColorScheme.fromSeed` sehingga warna komponen mengikuti tema aplikasi dan tidak ditentukan satu per satu.



\## 2. Bentuk Status



\*\*Pilihan:\*\* Status ketersediaan produk ditampilkan dalam bentuk teks pada bagian kanan kartu produk.



\*\*Alasan:\*\* Status dibuat singkat agar pengguna dapat mengetahui kondisi produk dengan cepat tanpa harus membuka halaman lain. Status "Tersedia" menggunakan warna utama tema, sedangkan status "Habis" menggunakan warna error dari tema agar perbedaannya mudah dikenali.



\## 3. Posisi Aksi Utama



\*\*Pilihan:\*\* Tombol "Tambah Produk" ditempatkan sebagai Floating Action Button di bagian bawah layar.



\*\*Alasan:\*\* Tombol dibuat mudah ditemukan karena penambahan produk merupakan salah satu tindakan utama pada halaman daftar produk. Posisi tersebut juga membuat tombol tetap mudah dijangkau ketika pengguna melihat daftar produk.



\## 4. Hierarki Teks



\*\*Pilihan:\*\* Nama produk dibuat lebih tebal, sedangkan harga ditampilkan sebagai informasi pendukung di bawahnya.



\*\*Alasan:\*\* Nama produk menjadi informasi yang paling mudah dikenali terlebih dahulu, kemudian pengguna dapat melihat harga dan status produk. Susunan ini membuat informasi dalam setiap kartu lebih sederhana dan mudah dipindai.



\## 5. Empty State



\*\*Pilihan:\*\* Menampilkan ikon dan teks "Belum ada produk tersedia" ketika daftar produk kosong.



\*\*Alasan:\*\* Empty state digunakan agar pengguna tidak melihat halaman kosong tanpa penjelasan. Pengguna dapat langsung mengetahui bahwa belum ada produk yang tersedia pada sistem.
