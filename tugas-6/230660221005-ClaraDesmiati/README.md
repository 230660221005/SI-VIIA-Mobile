## Deskripsi Tugas

Tugas ini mengembangkan aplikasi SiAngkut dengan navigasi antarlayar, pengiriman data jadwal melalui arguments, form laporan dengan validasi, serta feedback menggunakan SnackBar. Implementasi dibuat menggunakan Flutter tanpa package tambahan dan masih menggunakan data contoh, sehingga pengiriman laporan belum tersimpan secara permanen.

## Refleksi

Bagian yang paling sulit bagi saya adalah menjaga konsistensi nama route antara diagram navigation flow, peta routes pada MaterialApp, dan pemanggilan Navigator.pushNamed. Hal ini perlu diperhatikan karena perbedaan penulisan route dapat menyebabkan halaman tidak ditemukan saat tombol ditekan. Saya juga belajar bahwa arguments, validasi form, dan feedback harus bekerja bersama agar alur pelaporan mudah dipahami pengguna.
