## Deskripsi Singkat

Tugas ini berisi analisis kebutuhan untuk aplikasi SiAngkut, yaitu rancangan aplikasi layanan informasi angkutan sampah. Dokumen mencakup deskripsi aplikasi, dua user persona, kebutuhan fungsional dan nonfungsional, prioritas fitur dengan MoSCoW, pemetaan kebutuhan ke antarmuka, serta user flow untuk melaporkan pengangkutan yang belum terlaksana.

## Refleksi

Bagian yang paling sulit bagi saya adalah merumuskan kebutuhan fungsional, karena setiap kebutuhan harus berfokus pada satu fungsi dan dapat diuji. Saya juga perlu membedakan prioritas Must have dan Should have agar fitur utama SiAngkut tetap realistis untuk versi awal. Menyusun user flow cukup menantang karena setiap titik keputusan harus memiliki cabang gagal yang berakhir jelas atau kembali ke langkah yang tepat.
