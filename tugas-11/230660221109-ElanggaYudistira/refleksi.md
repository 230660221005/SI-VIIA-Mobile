# Refleksi Tugas 11

Fitur foto bukti transaksi dipilih karena mendukung proses bisnis pencatatan MoneyTrack dan menghasilkan data yang dapat dikaitkan dengan satu transaksi. Bagian konfigurasi yang paling sulit adalah membedakan perilaku file chooser web dari permission kamera pada Android atau iOS, sehingga service menerjemahkan PlatformException menjadi status yang dapat dipahami halaman. Pemisahan service dan widget membuat pemilihan gambar, pembatalan XFile null, permission ditolak, dan error dapat diuji tanpa menaruh pemanggilan package langsung di method build.

Deklarasi penggunaan AI: ChatGPT membantu menyusun draf service, state UI, dokumentasi, dan jawaban quiz; penulis meninjau, menjalankan, serta memverifikasi hasilnya.
