## Deskripsi Program

Program Modul Hitung Nilai dibuat menggunakan bahasa pemrograman Dart untuk menampilkan komponen penilaian, bobot, dan skor. Program menghitung rata-rata skor dari lima komponen, kemudian menentukan predikat akhir berdasarkan aturan yang telah ditentukan.

## Hasil Keluaran Program

Program menampilkan lima komponen penilaian dengan rata-rata skor sebesar 18.00 dan predikat akhir A.

## Refleksi

Sintaks `List<Map<String, Object>>` perlu diperhatikan karena setiap komponen penilaian harus memiliki kunci dan tipe data yang konsisten. Saya juga belajar menggunakan `as int` untuk mengambil nilai skor dari Map agar dapat dijumlahkan. Penggunaan fungsi dengan tipe kembalian `double` membantu menghasilkan nilai rata-rata yang dapat ditampilkan dalam bentuk desimal.
