\### 1. Apa yang dimaksud dengan validasi input?



Validasi input adalah proses pemeriksaan data yang dimasukkan atau dipilih pengguna untuk memastikan data tersebut sesuai dengan aturan yang ditentukan sebelum diproses oleh aplikasi.



\### 2. Mengapa validasi input penting dalam aplikasi?



Validasi input penting untuk mencegah data yang tidak sesuai, mengurangi kesalahan pemrosesan, dan membantu menjaga keamanan aplikasi.



\### 3. Apa perbedaan validasi client-side dan server-side?



Validasi client-side dilakukan pada aplikasi atau perangkat pengguna sebelum data dikirim, sedangkan validasi server-side dilakukan pada server untuk memeriksa kembali data yang diterima.



\### 4. Mengapa aplikasi perlu membatasi format dan ukuran file?



Pembatasan format dan ukuran file membantu mencegah file yang tidak sesuai diproses serta mengurangi risiko penggunaan sumber daya secara berlebihan.



\### 5. Apa fungsi HTTPS dalam aplikasi?



HTTPS mengenkripsi komunikasi antara aplikasi dan server sehingga data yang dikirimkan lebih terlindungi dari penyadapan dan perubahan oleh pihak yang tidak berwenang.



\### 6. Mengapa token autentikasi harus disimpan dengan aman?



Token autentikasi harus disimpan dengan aman agar tidak mudah diakses atau disalahgunakan oleh pihak lain untuk mengambil alih akses pengguna.



\### 7. Apa fungsi permission pada aplikasi mobile?



Permission digunakan untuk meminta persetujuan pengguna sebelum aplikasi mengakses fitur atau sumber daya perangkat, seperti kamera dan galeri.



\### 8. Apa risiko jika aplikasi tidak melakukan validasi file?



Aplikasi berisiko menerima file dengan format yang tidak sesuai, ukuran berlebihan, atau isi file yang tidak valid sehingga dapat menyebabkan kesalahan pemrosesan dan masalah keamanan.



\### 9. Sebutkan validasi yang diterapkan pada aplikasi Tugas 12!



Validasi yang diterapkan meliputi:

\- Foto wajib dipilih.

\- Format file harus JPG, JPEG, atau PNG.

\- Ukuran foto maksimal 2 MB.

\- Data foto tidak boleh kosong.

\- Signature awal file harus sesuai dengan JPEG atau PNG.



\### 10. Mengapa pengujian keamanan perlu dilakukan?



Pengujian keamanan diperlukan untuk memastikan validasi berjalan sesuai aturan, menemukan kelemahan aplikasi, dan mengurangi risiko kesalahan maupun penyalahgunaan aplikasi.
